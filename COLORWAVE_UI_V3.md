# ColorWave UI v3 — OEM Liquid Glass

Visual direction:
- Neutral near-black / light system background.
- Explicit on-surface text colors to prevent dark-on-dark labels.
- No duplicated ColorWave branding in the hero.
- Animated three-layer waveform.
- Moving ambient color fields behind translucent surfaces.
- Floating glass-style bottom navigation.
- OEM 2-column sound profile cards.
- Compact unified sound-shaping panel.
- Studio category navigation instead of one giant effect list.
- Glass-like System and Engine surfaces.
- No external image assets required.

The visual effects are GPU-rendered Compose gradients/animation; no bitmap loop/background video.
